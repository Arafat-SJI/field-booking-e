PROJECT DESIGN SPECIFICATION Field Booking Site — UI Design Requirements Visual, Layout, and Component Design Standards for Core User-Facing Pages Document Scope: This specification defines strictly the visual appearance, layout architecture, typography, color hierarchy, and UI component styling for four core pages: Login, Registration, Home, and All Fields. Backend logic, authentication flows, booking engines, and interactive behaviors are excluded from this document. 1. Global Design System & Visual Language All four pages must adhere to a unified, athletic, and clean visual identity inspired by outdoor sports venues and modern turf facilities. Layouts must remain airy with generous whitespace, crisp card borders, and clear typographic contrast. Design Token Specification Visual Application Primary Brand Color Deep Turf Green (#065F46) Primary buttons, active navigation indicators, section headings, and brand accents. Secondary Accent Vibrant Pitch Emerald (#10B981) Hover states, availability indicators, subtle highlight borders, and badge accents. Canvas & Surfaces Off-White (#F8FAFC) / Pure White (#FFFFFF) Page background in soft off-white; elevated form containers and field cards in pure white. Typography & Text Sans-Serif (e.g., Inter / Plus Jakarta Sans) Dark Slate (#0F172A) for headings; Cool Gray (#475569) for body copy and labels. Borders & Radii 1px Solid Border (#E2E8F0); 8px–12px Radius Consistent rounded corners on inputs, buttons, and venue cards with crisp hairline borders. 2. Login Page Design Requirements The Login page must feature a distraction-free, centered layout designed for immediate visual focus on the sign-in container without global navigation clutter. Page Layout Structure: Split-screen desktop composition (50% left editorial sports venue photograph with subtle dark gradient overlay; 50% right centered authentication canvas) collapsing into a single centered card on smaller viewports. Brand Header: Site logo mark and wordmark positioned at the top of the form container, followed by a bold welcome headline (e.g., "Welcome Back") and a single-line muted subheading. Field Booking Site — UI Design Requirements Page 1 of 3 Form Input Styling: Vertical stack of full-width input fields (Email Address and Password) with clear top-aligned labels, 44px–48px input height, subtle placeholder text, and an inline eye-icon toggle inside the right edge of the password field. Auxiliary Controls Row: Horizontal flex row directly below the password field containing a custom-styled "Remember me" checkbox on the left and a muted green "Forgot password?" text link on the right. Primary Action & Footer Link: Full-width solid Deep Turf Green primary button ("Sign In") with bold white text, followed by a centered secondary prompt ("Don't have an account? Sign up") anchored below a thin horizontal divider. 3. Registration Page Design Requirements The Registration page must mirror the visual DNA of the Login page to maintain seamless onboarding continuity while accommodating multi-field account creation cleanly. Page Layout Structure: Matching split-screen or centered card shell with slightly wider form container padding (max-width 480px) to prevent vertical crowding. Header & Progress Cue: Concise title ("Create Your Account") and brief value proposition subtitle aligned left with the form inputs. Field Grouping & Grid: Two-column side-by-side row for First Name and Last Name, followed by full-width stacked inputs for Email Address, Phone Number (with country code prefix styling), Password, and Confirm Password. Password Strength Visual Indicator: Minimalist horizontal segmented bar (4 thin segments) directly beneath the password input to visually communicate password complexity tiers. Legal Consent & Submit CTA: Clean checkbox alignment for Terms of Service and Privacy Policy acceptance with underlined inline links, followed by a full-width primary CTA button ("Create Account") and a bottom link back to the Login page. 4. Home Page Design Requirements The Home page serves as the visual showcase for the platform, structured into distinct horizontal bands with strong photographic appeal and clear typographic hierarchy. Top Navigation Bar: Sticky full-width white header (72px height) with bottom hairline border; brand logo on the left, centered navigation links (Home, All Fields, Locations, About), and right- aligned Login text button paired with a solid green Sign Up button. Hero Banner Section: Full-width hero container featuring high-resolution aerial stadium/turf photography, dark gradient scrim for text legibility, large display headline, concise subheadline, and an integrated horizontal search bar capsule (Sport Type, Location, Date) with a prominent search CTA button. Sport Category Strip: Horizontal grid of 4 to 6 clean category tiles (e.g., Football, Cricket, Tennis, Basketball, Badminton) featuring minimal line icons, bold sport titles, and venue count subtitles. Field Booking Site — UI Design Requirements Page 2 of 3 Featured Fields Showcase: 3-column card grid highlighting top-rated venues, accompanied by a section header on the left and a "View All Fields" ghost button on the right. How It Works & Footer Band: A 3-step horizontal visual guide (numbered badges with clean titles and short descriptions) over a light tinted band, concluding with a dark slate 4-column footer containing brand summary, quick links, contact details, and copyright notice. 5. All Fields Page Design Requirements The All Fields page must prioritize scannability, visual comparison across multiple sports venues, and structured filtering without visual clutter. Page Title Header: Compact top banner displaying the page heading ("Explore All Fields"), total venue count subtitle, and a right-aligned "Sort By" dropdown selector. Two-Column Directory Layout: Left-hand fixed-width filter sidebar (260px–280px width) paired with a main fluid right-hand venue grid area. Filter Sidebar Styling: Clean white panel divided by subtle horizontal rules into collapsible filter groups: Sport Category (checkbox list), Surface Type (Natural Grass, Artificial Turf, Hard Court), Price Range (dual-thumb range slider visual with min/max value boxes), and Amenities (Floodlights, Parking, Changing Rooms). Field Card Anatomy: Uniform 3-column responsive grid where each card features a 16:9 venue photograph with a top-left sport tag badge, bold venue name, location pin icon with neighborhood text, star rating display, hourly rate typography (e.g., bold price + "/ hr"), and a full-width outlined "View Details" button. Pagination Controls: Centered bottom navigation bar displaying previous/next arrow buttons and numbered square page indicators with active green fill styling.
